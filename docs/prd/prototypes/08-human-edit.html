# 第三章：雾中的航标

清晨五点，岑望推开潮湿的木门。雾压得很低，灯塔的光每隔七秒扫过堤岸。

他没有去港口，而是绕向旧船坞。昨夜信封里的盐粒，与船坞门前的一模一样。

“等潮水退去，你就会明白。”他在心里默念，没有拆开第二页。

旧航标忽然响了两声。岑望停下脚步——那不是风。
