# 数据库监控：表统计与慢查询诊断

## 范围与事实来源

用户反馈数据库表容量均为“-”、列表未遵循通用组件，以及锁续租/心跳更新大量超过1000ms。依据为`platform_monitor/database.rs`、`PlatformMonitor.tsx`、共享`ResourceTable`及SeaORM 2.0.4驱动：SQL统计计时在连接池acquire之后开始，包含语句往返、数据库执行和服务端锁等待，不包含获取连接的等待。截图不能独立确定线上慢因。

本期补三种数据库的只读表元数据、共享列表与查询状态、当前数据库等待摘要。保留1000ms阈值；不修改线上数据库参数、不自动重置统计、不执行VACUUM/ANALYZE/逐表COUNT、不开放SQL控制台、不更改心跳或租约安全规则。Native模板后续继续，本轮不部署线上或4291、不发版。

## 数据与接口

新增管理员只读`GET /api/platform/monitor/database/tables`，返回既有列表信封`items/total/page/page_size`。参数q≤200字符；kind为空/table/view；sort仅name/kind/estimated_rows/bytes/data_bytes/index_bytes，可带负号倒序；page≥1，page_size为1～200。未知过滤/排序取值拒绝，名称排序作为稳定次序，空数值始终置后。SQL仅使用固定方言查询，不拼接用户表名或排序字符串。目录只查当前数据库、PostgreSQL当前schema。

| 字段 | 类型与规则 |
|---|---|
| name | 元数据中的表名/视图名；列表行键 |
| kind | table/view；只读固定枚举 |
| estimated_rows | 非负整数或null；数据库已有统计估值，非精确COUNT；缺统计不伪造0 |
| bytes | 非负整数或null；数据与索引总占用 |
| data_bytes / index_bytes | 非负整数或null；分别为数据与索引占用 |
| size_status | available / unavailable / not_applicable；视图无独立存储为not_applicable |

PostgreSQL用pg_class/pg_namespace和pg_total_relation_size/pg_table_size/pg_indexes_size，reltuples未初始化时行数为null；包含物化视图与分区关系元数据，分区父表不重复累加子表。MySQL用当前DATABASE的information_schema.TABLES；估值遵循存储引擎统计。SQLite用sqlite_schema与dbstat聚合表/所属索引页；dbstat不可用时保留目录并标不可用，不因此使整页失败。SQLite不为估值运行额外全表扫描。

当前数据库等待摘要仅支持PostgreSQL已有系统视图：按state/wait_event_type/wait_event汇总会话数，以及被阻塞会话数、最长事务秒数。只查当前数据库、排除监控自身，不返回SQL正文/参数/客户端地址。查询被拒绝为unavailable；状态字段受数据库角色可见性限制，缺失显示unknown；其他方言为unsupported。摘要是请求时刻快照，累计慢查询统计不会因当前无阻塞而清零。

## 评审与验收

| 维度 | 明确规则 |
|---|---|
| 本期/不做/灰度 | 上述只读统计与列表；无灰度，旧overview字段保持兼容 |
| 事实/配置/状态 | 方言系统元数据；1000ms沿用原定义；数据库连接沿用运维配置 |
| 流程/模式/联动 | 进入表Tab加载列表；搜索提交、排序/分页写URL；无新增/编辑/删除/批量操作；刷新重新采集 |
| 空/加载/错误/极值 | 无匹配复用列表空态；复用骨架和重试；容量缺失显示状态；长表名换行，0显示0，最大值不截成负数 |
| 权限/审计/删除 | 沿用平台Admin，匿名401、普通用户403；查询不新增业务审计；无删除 |
| 模型/时间/索引/DDL | 无持久化模型或审计字段，无DDL/索引/迁移up/down；只读数据库已有目录 |
| 计算 | 数字按数值排序；bytes=data+index的方言口径；空值不参与汇总冒充0；无金额计算 |
| 校验/冲突/兼容 | 参数白名单；不影响租约/ID分配/业务事务；旧数据库overview兼容 |
| 历史/三方/核心流程 | 无历史变更；复用已有数据库驱动，无新增依赖；核心业务执行不变 |
| 文案 | 新增说明/状态覆盖现有六语，至少zh-CN/en-US/ms-MY，长文案允许换行 |
| 测试/追踪 | 实库验证存储数值、视图、过滤/数值排序/分页及管理员边界；三尺寸列表/URL交互。Figma暂缺，截图存维护证据目录，未截图不声称覆盖 |
| 评审结论 | 只读字段/权限/计算/状态明确，可以实施；线上实际慢因仍需实际等待摘要或数据库证据，不以本地结果代替 |
