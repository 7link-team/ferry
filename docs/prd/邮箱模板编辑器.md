# 邮箱模板编辑器

## 纠正契约（2026-11-09，覆盖下文旧事件/语言范围）

用户明确要求语言配置，并指出“测试”是操作而非模板类型。编辑页仅配置注册验证码业务模板，删除code/test类型下拉；不新增业务事件。语言下拉复用六种系统语言，默认当前界面语言，URL记录mail_locale；切换保留各语言未保存内容，保存使用原平台设置版本锁与权限。

加密mail_config新增code_templates对象，键仅允许六个完整语言标签，每项subject/body/html。主题200字符、正文及HTML各16384字节，沿用验证码必含{{code}}、变量白名单及禁止标题换行校验。全对象替换随同平台设置保存；不新增表、时间字段、索引或DDL。旧JSON缺字段反序列化为空对象，up无需迁移；旧字段保留且不覆盖。发送按原请求语言协商结果选择该语言配置，未配置该语言沿用旧通用code字段，再回落该语言默认值；显式重置保存空配置则直接使用该语言默认值。旧test字段只保留兼容存储，不再作为可选模板。

发送测试复用原超管SMTP端点，接收所选语言和当前草稿，按同一渲染函数发送示例验证码123456，不写email_codes、不创建模板、不覆盖模板。仅SMTP连接配置须已保存，模板草稿可直接测试；成功更新原SMTP验证时间/版本与审计，发送失败保留草稿并显示错误。测试成功不代表收件箱实际投递；并发配置变化继续原409保护。

插入变量按钮位于富文本/HTML切换栏右侧；使用共用Radix菜单，展示变量名、用途及示例。{{email}}明确为收件人邮箱：注册时为待验证邮箱，测试时为填写的测试地址；{{code}}为验证码，{{expires_minutes}}为分钟有效期。选取后插入最近编辑字段的选区；只读不显示插入/测试/重置。菜单键盘可达、可Esc退出，Phone在工具栏内换行并约束菜单宽度，核心操作不丢失。

评审：事实来源为上述用户纠正及现有Configuration/注册发送/平台SMTP；本期范围如上，PXC另行恢复。无灰度、无新依赖/权限/业务事件/数据库迁移；旧配置兼容，旧版本回退不会读取语言配置，需使用更新前备份恢复才能完整回退。保存与测试沿用原审计；预览、语言切换、菜单不提交。默认/空/加载/错误、长语言标签、超长正文/未知语言/未知变量均纳入测试；六语文案齐全，无新时区/金额逻辑。列表/新增无此页面模式，编辑可改、查看只读；删除无，重置仅当前语言且保存前可取消。响应式沿用下文三类矩阵，语言/重置在顶栏、变量在编辑器工具栏；Figma暂缺、虚拟键盘实机未覆盖。验收追踪为mail.rs单测及test-mail-template-workspace-ui.mjs真实SMTP/浏览器证据，代码完成不算用户验收。

## 注册验证码配置（2026-11-09 用户新增）

事实来源为用户提出的注册验证码开关/有效时间和现有accounts/mail.rs签发、消费与SMTP验证机制。本期在账号注册tab新增验证码配置区，开关仅在SMTP启用且验证成功时生效；默认保持历史行为（开关开启、10分钟）。有效时间为整数1–60分钟，前后端一致；按新签发时刻计算expires_at=updated_at+分钟×60000。调整有效时间不修改已签发记录、不改变配置tag；SMTP/凭据变化仍按既有规则失效旧验证码。测试样例不签发验证码；修改有效时间须先保存再发送模板测试。默认模板与预览改用expires_minutes，自定义正文中的字面数值不自动改写。

范围外：密码找回、邀请码、多个验证码类型、验证码记录清单、生产SMTP发送。无灰度；沿用平台超管鉴权/设置审计、现有邮箱限流/单次消费/失败次数与数据隔离。开关不删除历史记录；已过期记录按现有签发清理。无金额/舍入；时间单位为分钟，接口expires_in秒。数据存既有加密mail_config新增可选JSON键code_enabled/code_valid_minutes；默认回填仅在读取层，无新表/时间戳/索引/DDL，无数据库up/down迁移，旧节点可读未知JSON键但不具备新策略，滚动发布需统一服务器版本；不承诺旧服务执行新配置。新服务兼容历史配置。前端六语、变量语义/只读/空默认/范围校验/保存错误保留草稿，使用现有CRUD表单。

Desktop沿用两列表单；Pad按容器单/双列；Phone单列且保存底栏可达；页面仅纵滚、输入与帮助换行，导航保留现有section/form_tab/at状态，安全区与键盘沿用通用表单。三类尺寸走通保存/回读并截图；Figma与原生键盘暂缺。验收映射scripts/test-mail-template-workspace-ui.mjs的TEST_CODE_CONFIG：UI四宽度、1/60边界与非法值、真实SMTP正文与DB到期一致、签发后改配置仍能消费、开关/SMTP依赖与公开注册状态；单元测试覆盖旧配置回退与六语变量。其余评审维度沿用本文矩阵，无新增第三方依赖或权限名；核心影响为验证码签发/注册，历史自定义模板不改写。
