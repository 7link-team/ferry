| 评审维度 | 契约 |
|---|---|
| 本期范围 | 预览、下载独立；文本/Markdown/JSON/XML显示纯文本；图片音视频沿用媒体控件；具体来源新标签打开 |
| 不做范围 | 不编辑文件，不执行HTML，不转换Office/PDF，不删除或搜索内容 |
| 灰度策略 | 无，随本地更新交付 |
| 流程闭环 | 点击预览→加载→内容/空文件/错误重试；关闭取消正文请求；下载独立 |
| 异常覆盖 | 空文件明确提示；仅显示前256KiB并提示截断；失败可重试；不支持格式仅下载；无来源不伪造链接 |
| 操作记录 | 只读不新增业务操作，沿用访问统计 |
| 删除保留 | 无删除，保留策略不变 |

| 计算逻辑 | 浏览器读取上限256×1024字节并取消流；服务端沿用加密Store和32MiB文件限制 |
| 模式差异 | 仅查看；弹层标题/底部固定，正文滚动；不写回数据 |
| 字段联动 | MIME决定预览方式；artifact定位构建执行；asset优先同空间执行所属工作流，其次同空间工作流引用；无来源显示缺失 |
| 状态操作 | 来源target=_blank、rel=noopener noreferrer；原目录筛选分页位置保留；错误不阻断下载/关闭 |
| 校验规则 | ID和Range沿用解析；文本经React转义，NUL字节拒绝文本预览 |
| 数据模型 | 使用既有assets/asset_refs/workflows/workflow_executions/pipeline_artifacts，无模型变更 |
| 时间审计 | 无新增xx_at/xx_by |
| 索引设计/SQL示例 | 无DDL；沿用ID/工作空间/引用索引；查询来源同时匹配workspace |
| 文案完整 | 六种现有语言，包含zh-CN/en-US/ms-MY |
| 配置来源 | 固定预览上限为实现约束，MIME/来源读取既有数据；无字典配置 |
| 状态覆盖 | 加载、内容、空文件、截断、失败、不支持、来源缺失 |
| 影响核心流程 | 预览/下载；共用字节响应需回归Range和空间ACL |
| 影响历史数据 | 否，无up/down迁移，无写回 |
| 三方依赖 | 无新增，复用React/Radix和存储 |
| 版本兼容 | 新增平台只读内容端点；原空间ACL不变 |

| 可测试性 | 真实内容、转义、上限、空文件、重试、来源、真实上传/下载、401/403、跨空间ACL |
