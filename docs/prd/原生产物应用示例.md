# 原生产物应用示例

## 范围与项目依据

为新空间初始化一组手动执行的配套模板：Actions 构建 HTTP 可执行文件，以及引用该流水线产物的 Native 应用。复用 templates::seed_examples 的空间事务、模板参数展开、既有 Actions 归档、部署预览与 systemd 驱动。事实依据为 templates.rs、deployments/manifest.rs、pipelines/artifacts.rs 和 test-deployments.py 的 Native SSH/HostAgent 验收。

本期不增加调度器、插件、部署模式、数据库表或自动运行策略；不宣称此无状态单服务示例包含数据库 HA、多机仲裁、持久卷迁移或生产流量入口。保留原容器 HTTP、依赖构建、节点工作流示例。已有空间不回填，不覆盖用户编辑或删除的数据。

## 操作与数据

创建空间只保存模板，不创建运行中的流水线或应用。用户从构建模板创建流水线，选择自己的主机，手动构建成功后，从 Native 应用模板创建应用并指定该流水线名称或 ID。Native 的产物定位、同名歧义、跨空间拒绝、归档 SHA 校验、预览确认和历史回滚沿用既有接口与规则。构建模板无主机、仓库或流水线的本地 ID。

构建使用 Bash 和 Python 3 标准库，不下载第三方程序；产物路径为 app，包含 Python shebang 和执行权限。部署主机需要 Python 3、systemd，以及既有 Native 驱动要求的操作权限。应用从 PORT 和 WELCOME_MESSAGE 环境变量读取监听端口和响应正文；GET / 返回正文，GET /health 返回健康状态，其他路径返回 404。仅绑定用户所选主机的空闲端口，不执行模板参数中的 shell 文本。

| 参数 | 类型、默认与约束 | 来源和清空规则 |
|---|---|---|
| pipeline | 字符串，必填，1～200 字符，无默认值 | 用户填写本空间流水线名称或 ID；空值阻止生成 |
| port | 整数，默认 8080，1～65535 | 用户配置，写入 PORT、服务端口与健康检查端口；非整数或越界拒绝 |
| message | 字符串，默认当前语言的已有 HTTP 欢迎文案，1～2000 字符 | 用户配置，仅作为环境变量数据；空值拒绝 |

产物路径固定为 app，与构建模板保持一致。复用的整数端口参数在服务端口字段保持整数，在 manifest 的 env.value 字符串字段展开为十进制字符串；此规则也适用于该字段的布尔参数，不改变其他字段的类型保持规则。系统资源限额、无副本扩展与 Native 可表达范围沿用 manifest 校验。构建默认只手动触发；应用只有执行预览并确认才部署，修改模板不修改已创建的应用或历史归档。
