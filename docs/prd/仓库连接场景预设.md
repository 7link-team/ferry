# 仓库连接场景预设

事实依据为《应用高可用拓扑与多部署驱动方案》§11.5、现有 RepositorySource、auth/connection.rs 和 repository monitor API。本期在现有创建表单加入 GitHub 团队构建、Codeup 企业仓库、纯 Git 拉取三种预设。复用平台选择、凭据选择、可选 Git URL、Codeup 组织与现有 CRUD；不增加模板表、市场菜单、连接记录或自动执行。

预设仅在无 id 的新增模式显示。选用即设置平台并清空旧凭据、地址和组织，行为与当前切换平台一致；连接名称和备注保留。预设不填组织ID、仓库地址、密钥或示例凭据。用户可以继续切换平台或调整参数；手动切换平台取消预设提示。编辑和查看模式不出现预设。GitHub/Codeup 仍要求已有凭据或现有网页授权；Git 沿用可选凭据及地址规则。监控订阅与通知在创建成功后的监控设置中显式开启，不混入连接授权提交。
