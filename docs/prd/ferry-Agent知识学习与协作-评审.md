## 2. 共用审查定位

- 权限：主PRD §3 AUTH-01–06；各API同时校验路径Scope、owner、当前会话成员、Agent/节点许可，门店维度无（非门店产品）。Web/H5/Tauri同后端契约。
- 状态：主PRD §5，未声明迁移409；错误、不可见、版本冲突不得success:true。过期状态实时计算不依赖定时扫描。
- 保留：RET-01–05；归档/引用保护/GC，无新自动TTL；来源失效涉及已有CLI上下文，不能承诺彻底撤回。
- 数据：数据文档§1–5完整字段/索引/三方言DDL，全部标拟定，不直接执行；无存量模型越权修改。
- 配置：主PRD§8、新settings JSON；限额是新设计P04，价格/用量依现有账本，不造数字。
- 页面：主PRD§7及本文件Screen追踪；共享资源组件、i18n三语、44×44、焦点、字段错误、200%文本与安全区。
- 测试：主PRD§9为可执行规格；本次只文档/DDL设计校验，TC均NOT_RUN。
