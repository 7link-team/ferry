# 账号 OTP 二步验证

## 已确认需求与边界

用户确认采用密码 + OTP，兼容 Google Authenticator、Ente Auth 等标准 TOTP 应用。平台开启个人绑定入口；账号拥有者扫码绑定，验证后生效；绑定账号密码正确后进入独立第二步，完成前不签发登录会话。提供一次性恢复码。复用现有 Account、平台 Admin、加密 Vault、共享数据库登录限流和平台审计。

平台开关控制新绑定；关闭入口不删除绑定、不让已绑定账号绕过第二步。默认关闭，存量账号和会话不自动绑定；不自动为管理员或用户启用，不新增强制全员策略。无短信OTP、无邮件替代第二步、无管理员读取/重置用户密钥、无外部二维码服务、无Workspace级OTP配置、无记住设备。验证器真实手机扫码由用户验收，不冒称已测物理设备。

## 可判定业务规则

- RFC 6238：SHA-1、6位、30秒，允许前后一个时间窗口。服务器时间为依据；已成功消费的时间步不可再次使用。
- 绑定需要当前密码，生成20字节随机密钥和本地二维码；10分钟内输入有效动态码确认后才生效。重新开始替换未确认密钥，已确认绑定不得直接覆盖。二维码/密钥仅本人本次展示，不经外部图片服务。
- 确认绑定生成10个128位随机恢复码，仅当次展示，可复制/下载保存；数据库不存可直接使用的恢复码原文。每个码仅成功使用一次。重置整组恢复码、解除绑定都需当前密码 + 当前OTP或剩余恢复码；确认绑定、重置和解除均撤销其他登录会话。
- 密码正确后发5分钟、一次性的随机第二步凭证，绑定用户、客户端IP、当前密码版本和OTP绑定版本；不写Session、不更新最后登录。第二步最多5次验证，成功原子消费凭证/OTP时间步或恢复码，之后签发正常会话并更新最后登录信息。账号停用、密码改变、绑定解除或重新绑定后旧凭证不可用。
- 登录第二步按IP每分钟20次、账号每分钟10次、单凭证最多5次验证；个人安全管理按账号每分钟10次，复用有容量约束的共享数据库限流。失败计数必须提交，不因返回错误回滚。多实例在现有平台事务锁下串行消费，不能重复消费恢复码或重复使用时间步。
- 所有账号安全接口只从Account获取本人ID，不接受客户端指定其他用户；平台配置只允许平台管理员。前端隐藏不代替API鉴权，Workspace角色不改变账号OTP身份。

## 数据模型与迁移

新增 `user_otp`，一账号一行；认证材料以Vault和用户ID绑定加密。具体字段如下，payload JSON为内部加密对象：已确认密钥/恢复码哈希/已消费时间步/绑定版本/未确认密钥与失效时间。原有users不新增字段，防止广泛构造回归。短期登录凭证复用login_guards的有上限、可清理存储。

| 字段 | 类型 | 必填/默认/约束 |
| --- | --- | --- |
| user_id | BIGINT | 主键，非空；引用现有用户ID，应用层检查用户存在与启用 |
| payload | TEXT / MySQL LONGTEXT | 非空，Vault加密，AAD含user_id；不对外回显 |
| created_at | BIGINT | 非空，创建时毫秒 |
| created_by | BIGINT | 非空，默认0；0=system |
| updated_at | BIGINT | 非空，最后更新时毫秒 |
| updated_by | BIGINT | 非空，默认0；0=system |

```sql
CREATE TABLE user_otp (
 user_id BIGINT NOT NULL PRIMARY KEY,
 payload TEXT NOT NULL,
 created_at BIGINT NOT NULL,
 created_by BIGINT NOT NULL DEFAULT 0,
 updated_at BIGINT NOT NULL,
 updated_by BIGINT NOT NULL DEFAULT 0
);
```

主键覆盖全部查询；无额外索引、条件唯一索引或绑定外键DDL。MySQL将payload替换为LONGTEXT，其余字段约束相同；SQLite/PostgreSQL使用TEXT。up新增空表、默认入口关闭，不改历史账号/会话/密码；down仅删除user_otp，需停服务且确认不再需要OTP才能执行，回退将丢弃OTP绑定材料，必须显式操作。

## 页面与状态

平台登录防护下展示OTP入口开关与关闭行为说明；个人账号用安全区域展示未绑定/绑定准备中/已绑定状态及对应动作。绑定弹层标题和操作栏固定，二维码、手工密钥及验证码在中间；确认后独立展示恢复码，并要求用户保存。默认、空态、读取中、错误均有明确反馈，失败保留用户输入。登录第二步单独弹层，动态码/恢复码可切换，支持取消回到密码登录；过期回退，不保留密码或凭证到浏览器持久存储。

| 维度 | 结论 |
| --- | --- |
| 事实来源 | 用户确认及项目现有Account/Admin/Vault/login_guard/session代码；RFC6238仅定义互通算法 |
| 本期 / 不做范围 | 见需求与边界；不增加密码替代登录或强制全员策略 |
| 灰度 | 无自动绑定；入口默认关闭 |
| 流程闭环 / 状态覆盖 | 见规则与页面；未验证不生效、成功前无Session、过期/重放/停用均拦截 |
| 异常覆盖 | 无密钥、过期、错码、恢复码耗尽、限流、重复绑定、停用账号、网络失败及长文案 |
| 操作记录 | 平台开关沿用配置审计；个人绑定/解除/恢复码重置审计仅记录动作，不记录密钥/码/二维码/凭证 |
| 删除保留 | 解除绑定物理删除认证材料，审计保留；临时凭证按到期清理 |

| 模式差异 / 字段联动 | 绑定、确认、恢复码管理、解绑、登录第二步分别独立；入口关闭不绕过既有绑定 |
