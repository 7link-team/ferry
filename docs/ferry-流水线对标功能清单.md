## 2. 实测中发现的、值得借鉴的具体交互

每一条都对应实际看到的行为，截图文件名在括号中。

**n8n 2.45.7**

1. 执行结果直接画在编辑画布上：节点显示 ✓/✗，连线标出条数，未走到的分支保持灰色（`05`）。
2. 改了参数后，下游节点立刻变为橙色“过期”状态（`08`、`13`）→ 对应 B14。
3. 从某个节点单步执行，上游复用固定数据（`17`、`19`）→ 对应 F5 和“从此任务重跑”。
4. 失败策略三选一，其中一种会在节点上多出一个 **Error 输出口**，可以连到处理分支（`11`、`12`）。
5. 重试可选“用当前保存的定义”或“用当时的原定义”，新执行标注 “Retry of execution #9”（`45`）→ 对应 G5。
6. 执行详情顶部显示所用版本，执行列表可按版本过滤（`37`、`38`）→ 对应 G7。
7. 编辑自动保存为版本，只有发布才对生产触发生效，发布时必须填版本名，有未发布改动时显示橙点（`33`–`36`）→ 对应 L4。
8. 底部日志面板：左侧是节点执行树，带耗时，运行中显示转圈；右侧是选中节点的输入输出（`06`）。
9. 右键菜单每项都标出快捷键，命令面板汇总全部操作（`13`、`62`）。

**ComfyUI 0.43.0**

10. 加载工作流后立即提示“发现 3 个问题”：问题节点红框标出，运行按钮变为 ⚠；问题面板按类型分组，每项可定位、可修复（`05`、`06`、`09`）→ 对应 B15。
11. 拖动连线时只有兼容的端口高亮；松手在空白处时，弹出已按类型筛选的搜索框（`13`、`14`）。
12. 增量缓存（实测）：
    - 不改动任何东西，6 个节点全部命中缓存，耗时 0.00s；
    - 改动一个节点，只重算它的下游；
    - **缓存命中在画布上没有任何标记**。这是反例，Ferry 的“复用”状态必须显式标出。
13. “执行到选定的输出节点”：只运行该节点所需的那部分子图 → 对应 F5。
14. 从历史“在新标签页中读取工作流”，打开的是当时提交的精确参数快照（`21`）→ 对应 G8。
15. 运行时错误给出完整的 Markdown 报告，可一键复制（`35`）→ 对应 G10。
16. 中断只在节点边界生效，被中断的执行显示为“失败”，这是反例 → 对应 F7：取消必须和失败区分开。
17. 忽略（透传）与静音（跳过）是两种语义，配色不同（`42`）→ 对应 B10。

### 3.3 原设计中需要纠正的判断

1. §3 的对标凭记忆写成，**以本清单为准**。§28.1 中“对标准确：PASS”的结论撤回。
2. 原设计 §20 认为“按流水线授权不在本期”。这一判断低估了 Flow 的基础能力，改为 D14。
