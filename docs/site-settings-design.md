# 站点设置与动态标签标题

## 实施计划（2026-11-10，用户已确认四页签）

目标：平台设置增加“站点设置”，包含基本信息、浏览器标签、页脚、页面脚本；站点名称与标签前缀可配置。
复用：Platform 的 ResourceForm、平台设置 GET/PATCH、Admin 提取器、行锁/version、审计、公开 footer 接口和 PlatformFrame 的单次读取。
执行：Direct；前后端共享接口与表单紧密关联，不委派。新增 site 配置模块与共享 React context；修改表单配置、名称显示、HTML 标题、平台设置序列化及新增迁移；不修改 Runner/协议/业务资源。
验收：保存/回读、刷新、首次 HTML、当前页即时更新、三语及六语默认名、可见性切换、关闭/空前缀、旧链接、错误和权限、三类布局。

| 评审维度 | 规则与依据 |
|---|---|
| 事实来源 | 本轮用户确认简称“AI 工作台”、动态路由标题、太阳/月亮及可配置，确认四页签；现有 Platform.tsx、PlatformFooter.tsx、accounts/platform.rs、assets.rs 为实现来源 |
| 本期范围 / 不做范围 | 配置站点名称、前缀开关及可见/隐藏前缀，归并页脚/脚本入口；不新增 Logo/Favicon、定时昼夜主题、脚本执行策略或租户级品牌 |
| 灰度策略 | 无 |
| 流程闭环 | 读取→编辑→提交→成功刷新公开配置；失败保留草稿；version 冲突按现有 409 拦截；关闭前缀保留已有值 |
| 异常覆盖 | 默认/读取中使用本地多语言默认；初次读取失败继续默认，后续失败保留最后成功配置；名称空回退；前缀空不显示；错误显示现有 API 本地化反馈 |
| 操作记录 | 原平台设置审计，附 site_updated 标记；不新增审计模型 |
| 删除保留 | 无删除；清空名称恢复默认；不迁移/清空页脚与脚本 |
| 权限规则 | 继承平台超管 Admin；工作空间成员不能写；公开接口只返回名称、前缀和已公开页脚，禁止返回脚本或其他平台配置 |
| 计算逻辑 | 无金额/库存；标题为 [前缀+空格]+[操作·页面名]+竖线+站点名称；无页面名时仅显示站点名称 |
| 模式差异 | 沿用平台设置 editInPlace；登录页和各路由只读；无新增/删除模式 |
| 字段联动 | site_name 默认空；前缀开关默认 true；可见前缀默认☀️、隐藏前缀默认🌙；关闭时输入隐藏但保留值；自定义名称跨语言一致，空名称采用当前语言默认名 |
| 状态操作 | visibilitychange 触发前缀更新；切语言/路由同步标题；卸载移除监听；无通知、无焦点抢占 |
| 校验规则 | 名称最多120个 Unicode scalar；每个前缀最多32个；拒绝控制字符和非字符串/非布尔类型；去首尾空白；空字符串允许；错误为400 |
| 数据模型 | platform_state 新增 site_config 可空 TEXT（MySQL LONGTEXT），默认NULL；JSON对象含上述四个字段；NULL及缺字段读取默认；现有id/version与其他字段不变 |
| 时间审计 | 不新增 xx_at/xx_by；继续现有审计表记录操作者和时间 |
| 索引设计 | 复用 platform_state.id 主键；无新索引 |
| SQL示例 | SQLite/PostgreSQL: ALTER TABLE platform_state ADD COLUMN site_config TEXT NULL; MySQL: ALTER TABLE platform_state ADD COLUMN site_config LONGTEXT NULL; 无其他新字段/索引 |
| 文案完整 | 新文案及错误覆盖zh-CN/en-US/ms-MY及现有zh-TW/ja-JP/ko-KR；用户输入是部署配置，不自动翻译 |
| 配置来源 | 超管低频修改；默认名称来自i18n；默认前缀来自站点配置默认值；无部署品牌硬编码 |
| 状态覆盖 | 首次加载/空配置/保存中/保存失败/版本冲突/可见/隐藏/关闭/空前缀；未知路由按现有解析与名称回退 |
| 影响核心流程 | 仅配置展示、标题及登录页名称；登录/权限/任务执行逻辑不变 |
| 影响历史数据 | 新增可空列，不回填已有行；up检查列存在后添加；down遵循现有页脚/脚本迁移约定拒绝删除，防止配置丢失；旧二进制忽略新列，可保留列回滚应用。不得对运行库自动执行迁移 |
| 是否依赖三方 | 无新依赖；使用浏览器Page Visibility API |
| 版本兼容 | 公开footer响应增加字段，保留content；旧客户端继续读取；新客户端缺字段时使用默认；settings PATCH缺site字段时保留已有值 |
| 逻辑冲突 | 删除i18n旧固定document.title赋值，App单一标题所有者；页脚/脚本存储和行为不变 |
| 可测试性 | Rust默认/部分更新/清空/类型与长度/迁移重复及保留/HTML转义；React路由/语言/可见性/开关/即时刷新/失败；真实浏览器表单保存、回读和响应式 |
| 验收追踪 | tests对应document-title.test.tsx、scripts/test-site-settings.mjs、accounts/site.rs及assets.rs测试；Figma暂缺，不声明设计稿覆盖 |
| 响应式交付 | Desktop≥1200侧栏+内容；Pad768–1199沿用折叠分类及自适应字段；Phone320–767单列，四页签具名tablist容器内横向滚动，触控≥44，页面不横滚；无新弹层/固定底栏，沿用表单键盘行为；截图通过隔离测试输出，不提交截图 |
| 模糊描述 | 无 |

设备形态→布局重排→导航/操作→数据呈现→滚动→安全区/键盘：Desktop→分类侧栏+表单→键盘焦点可见→名称长文本换行→内容容器滚动→无新固定控件；Pad→现有响应式分类+字段→44px页签→名称换行→页签容器滚动→保留URL页签；Phone→单列→分类与44px页签→长名称break-word→只tablist横向滚动→无新遮挡层，输入沿用浏览器键盘滚动。
