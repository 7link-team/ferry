# v0.10.13-alpha

Date: 2026-11-23

## Android HTTPS connections

- Initialize Android's system certificate verifier before native connection and
  update requests. Previously, HTTPS requests could panic in a background task
  and leave the connection page waiting indefinitely.
- Package the verifier's Android companion at the version selected by Cargo.
  Certificate validation remains enabled.

## Native connection settings

- Reuse the Web interface's language and theme switchers in the bundled,
  offline connection page. The connection form, errors and update section use
  the selected theme, including light and dark appearances.
- Keep address drafts and update results when switching language. Native language
  changes preserve the exact bundled document URL required by native permissions;
  Web language routing keeps its existing behavior.
- Improve phone, tablet and desktop layouts, safe-area spacing, readable input
  sizes, keyboard access and long-text wrapping. Desktop connection and update
  text is available in Chinese, English and Malay, matching mobile.

## Application artwork

- Derive desktop, Android and iOS application icons from the same artwork as the
  Web interface. Build checks reject stale exports and mobile builds copy the
  generated icons into their native projects.

## Installation

These fixes require a new native client installation. Updating only the server
does not replace the installed connection page, TLS initialization or app icon.
Android packages remain debug-signed acceptance builds unless a persistent signing
key is configured. Cross-build installation compatibility depends on matching
signatures. The device IPA remains unsigned without an Apple signing team and
cannot be directly installed on a physical iPhone.
