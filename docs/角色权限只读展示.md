# 角色权限只读展示修正

问题：角色详情沿用通用 CRUD 表单，但多选字段的只读分支丢失了资源分组，重复动作名连成文本，无法判断授权范围。

修正：继续使用 ResourceForm 与现有权限目录，按原目录分组展示已选权限；每组显示名称和已选数量，动作逐项显示为独立标签。详情不提供复选框，不显示未授予动作。未知已存值沿用组件已有的回退选项，不删除、不改写。单组占满宽度，多组在大屏两列；窄屏单列，正文正常滚动。
