# 会话成员与身份头像

状态：实现与验证中；未验收。事实来源：`accounts/auth.rs`、`accounts/preferences.rs`、`agents.rs`、`conversations/groups.rs`、`Conversation.tsx`，以及用户关于成员详情、实时 Agent 状态、自动头像与上传/表情头像的要求。

## 功能契约

用户默认显示按身份 ID 稳定生成的人物插画；Agent 默认显示像素机器人。默认头像不调用外部服务、不回填数据库。个人资料与 Agent 表单支持人物、像素、姓名缩写、表情、上传图片；换一个仅变更种子。未保存修改不影响已存配置。历史消息的姓名沿用已有快照，头像展示当前身份设置。

上传只接受 PNG/JPEG/WebP，原文件≤5 MiB、每边≤8192像素。浏览器居中裁剪并缩放成128×128 PNG；存储值≤96 KiB。拒绝外部URL、SVG、控制字符、未知风格；种子≤96字节、表情≤64字节。头像为展示配置，不作为身份认证依据。

会话成员侧面板显示用户与Agent；点击展示身份ID、角色或该会话中Agent执行状态、最近完成的执行结果、运行时、模型与版本。复用现有每秒会话轮询，不新增定时器。queued/running/stopping沿用执行状态；待审批来自尚未决定且尚未发送的决策；无活动回合为空闲；刷新失败显示连接不可用。最近失败不等于仍在工作。人类在线状态未采集，不编造。成员状态仅指当前会话，不暴露其他会话活动。

发起单聊按钮仅在拥有 conversations.create、ai-agents.read、ai-agents.use 且存在导航回调时显示；服务端继续校验当前空间、Agent可用性与绑定。失败保留面板和错误信息，成功打开新会话。未新增人际私聊接口。

## 数据迁移

现有表 `account_preferences` 与 `ai_agents` 各新增 `avatar TEXT NULL DEFAULT NULL`，存储JSON文本。无额外必填字段或索引。既有审计字段不增删。SQLite/PostgreSQL/MySQL8均采用相同列声明；标识符按各方言转义，由SeaORM生成。

```sql
-- up (existing tables only)
ALTER TABLE account_preferences ADD COLUMN avatar TEXT NULL DEFAULT NULL;
ALTER TABLE ai_agents ADD COLUMN avatar TEXT NULL DEFAULT NULL;
-- down: removes only avatar overrides; back up before downgrade
ALTER TABLE ai_agents DROP COLUMN avatar;
ALTER TABLE account_preferences DROP COLUMN avatar;
```

本期不创建表，既有建表定义沿用已有迁移；以上增量DDL不添加未声明字段。回滚会丢弃新头像设置，用户/Agent记录不删除；先恢复旧二进制前须同步回滚新增迁移或恢复备份。
