# Avatar artwork notices

Avatars are generated locally with DiceBear 9.4.2. No identity or seed is sent to a remote avatar service. The generator code is MIT licensed; artwork licenses differ as listed below. Upstream license metadata remains embedded in generated SVGs, and the editor provides creator/style attribution links. Geometry is not modified; deterministic seed selection, 128px sizing and circular clipping are applied.

[Canva's seven-style article](https://www.canva.cn/learn/illustration-head-design/) informed the style discussion only. No article images, Canva templates or CryptoPunks artwork are copied or bundled. These presets are vector illustrations and pixel art, not commissioned gongbi paintings or reproductions of specific NFTs. Existing pixel robots and uploaded images are retained. Stored `portrait` values use the improved flat illustration; other existing stored style identifiers are unchanged. Additional style identifiers use the existing avatar JSON field and validator; no database migration or historical rewrite is needed.
