# alpha.6 功能完成度核对

核对基准：已发布 `v0.1.0-alpha.6`（0bb0f51），不是包含未提交变量模块的本地工作树。

## 实际界面覆盖

25 个工作空间导航入口中，10 个有已接入的资源列表，15 个进入“还未实现”占位页。缺失入口对应 11 类资源。平台管理的三个独立入口不计入该统计。

| 状态 | 功能 |
| --- | --- |
| 已接入页面 | 主机组、主机、标签、仓库、流水线、执行历史、凭据、应用、部署历史、操作记录 |
| 只有部分后端，页面缺失 | 仪表盘（计数 API）、角色管理（内置角色与只读接口，未提供完整管理界面） |
| 发布版未提供功能页面 | 成员管理、应用模板、流水线模板、应用市场、密钥变量、报警监控、定时任务、工作空间配置项、字典 |

- 成员：列表、姓名/邮箱搜索、详情、改角色、移除；邀请码查看与轮换；已登录账号可从菜单加入其他工作空间。
- 角色：列表、详情、自定义角色增改删、复制内置/自定义角色；权限按目录分组，自动补齐依赖，撤销依赖时撤销依赖它的权限。

剩余：应用/流水线模板、市场、变量与Compose接入、监控、定时任务、工作空间配置项、字典、导入导出；T8 密钥历史保留策略仍待原有决策，不在本轮擅自决定。
