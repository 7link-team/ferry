## 数据表

所有id/workspace_id使用BIGINT；引用在应用层按空间检查。渠道角色授权空数组表示任意具有发送权限的本空间角色。所有字段非空，除明确默认值外由写入方赋值。

- notification_channels：id主键；workspace_id；name VARCHAR(120)；description TEXT；provider VARCHAR(32)；enabled BIGINT默认1；config TEXT密文；role_ids TEXT数组；version BIGINT默认1；created_at/created_by/updated_at/updated_by BIGINT默认0。
- notification_templates：id主键；workspace_id；name VARCHAR(120)；language VARCHAR(16)；subject VARCHAR(256)；body TEXT；format VARCHAR(16)，text/html；version及四审计字段同上。
- notification_deliveries：id主键；workspace_id；channel_id/template_id/actor_id/agent_id BIGINT默认0；source VARCHAR(32)；source_id VARCHAR(128)；client_id VARCHAR(128)；request_hash VARCHAR(64)；state VARCHAR(24)；subject VARCHAR(256)；body TEXT；result TEXT；version及四审计字段同上。

正文和投递结果均受长度上限控制，不保存第三方原始响应及密钥；列表不加载正文。该阶段不声称记录已纳入平台自动清理，验收前必须记录保留边界。

告警引用扩展：同一迁移为 `alert_rules` 添加 `notification_channel_id BIGINT NOT NULL DEFAULT 0`，0 表示无公共渠道；建立 `(workspace_id, notification_channel_id)` 索引。存量 webhook 转为同空间渠道后，仅更新该引用，不修改规则版本、启停、阈值、事件及触发时间。新引用保存前检查发送权限和渠道角色；发送仍按原告警触发/恢复流程，幂等标识分别包含事件 ID 与 triggered/recovered，不补发历史事件。旧密文保留供整库降级恢复，降级不单独删列。

后台权限：MCP 发起的工作流在加密执行上下文中保留 `origin_agent_id`；后台执行与恢复重新校验调用账号和当前 Agent 角色，按交集执行，Agent 禁用或撤权立即阻断后续副作用。无此字段的历史人工执行保持原规则，不推断来源。

构建步骤复用现有 Actions worker 私有请求/响应通道，实现 `ferry/notify@v1`；支持 `channel-id`、`template-id`、`subject`、`body`、`format`、`to` 及 `variable-变量名` 输入。表单复用节点的消息参数组件，保留 YAML 双向编辑及 Actions 表达式。渠道密钥不下发主机，服务器按流水线发起人和加密变量快照中的 `origin_agent_id` 重新校验流水线对象、运行状态、发送权限及渠道授权。投递幂等键包含运行ID和当前 worker 调用随机nonce/请求ID摘要，重复日志不重复发送；中断任务按原有规则不重放。现有内置动作执行通道限 Native 任务，容器任务在保存时明确拒绝；容器构建可通过 needs 串联 Native 通知任务，本期不扩展容器内置动作运行机制。

SMTP沿用现有注册邮件的HTML转纯文本函数，HTML发送使用 multipart/alternative，不改变平台注册邮件配置或模板归属。

## 配套存储路径约束

平台文件存储配置增加可选 `storage_prefix`，S3 环境配置对应 `FERRY_ARTIFACT_S3_PREFIX`。共享对象存储层通过原生 PrefixStore 限定所有读、写、删及连通性验证请求；不增加二次存储系统。相对路径最多512字节，允许末尾一个 `/` 并规范化；拒绝绝对路径、反斜线、空段、`.`、`..`；空值保持原存储桶根路径。界面仅在S3模式显示，环境配置来源仍只读。

无新表、索引、DDL或历史数据改写，原配置的缺失字段默认空。已有文件时，平台修改前缀与切换bucket一样返回409要求先迁移；不提供跨业务目录读取回退。运维通过环境变量变更前缀时必须自行完成迁移，不能以环境配置绕过对象地址变更的事实。权限继续为平台设置权限；六语字段与帮助、原设置保存审计、CRUD三类尺寸契约均复用。无新删除/保留/计算/灰度策略或第三方依赖。验收为非法路径400、存量变更409、空兼容、同名对象在不同前缀互不覆盖/误删，以及真实S3文件加密/配额/回收回归；Figma暂无。证据 `data/maintenance/s3-prefix`。
