# 部署与数据导入

## 支持的部署目标

| 模式 | 目标与要求 | 更新与健康检查 |
|---|---|---|
| Compose | 已安装 Docker Compose 的 Linux 主机 | recreate；支持容器健康检查和部署就绪检查 |
| Docker | 已安装 Docker 的 Linux 主机 | 每服务一个容器；recreate |
| native | 已安装 systemd 的 Linux 主机 | 每服务一个 unit；ExecStartPost 检查与失败重启 |
| Swarm（stack） | 已加入 Swarm 的 manager 主机 | 支持滚动更新、期望副本数及任务就绪检查 |

上述模式可使用 Runner 或 SSH；执行身份需有管理目标服务的权限。K8s／Helm 暂缓。保存应用时校验模式能力，例如 native／Docker 不支持单机多副本，Swarm 不支持 Compose 的 depends_on 启动顺序。持久卷是节点本地数据，不提供跨节点复制。

配置先渲染、预览，再确认执行。预览与提交之间目标产物或关联配置变化时会要求重新预览。应用历史保存固定镜像摘要、完整执行产物及加密变量／配置快照，回滚不重新读取当前模板或当前密钥。

主机组只包含直接成员，按主机 ID 逐台执行。预览后成员变更会使预览失效；入队后固定成员，不受后续移组影响。首个失败即停，已成功主机不自动回滚。详情显示逐主机结果及当前版本，回滚采用历史目标列表。存在失败或部分成功时，先回滚或重新部署成功，再使用定时重启。

## 构建产物与配置文件

流水线定义的 `artifacts` 填写构建工作目录下的相对文件路径，例如：

```json
{
  "workdir": "/tmp/build/{{run}}",
  "steps": [{ "name": "build", "run": "make" }],
  "artifacts": ["dist/service"]
}
```

成功执行后服务端流式归档文件，记录 SHA-256、大小和文件模式。声明文件缺失会使构建失败。构建产物可下载；native 模式使用归档的可执行文件，不从之后可能改变的构建目录取文件。

```yaml
services:
  - name: api
    artifact:
      source: pipeline
      pipeline: "流水线 ID 或唯一名称"
      path: dist/service
    files:
      - path: /etc/service.conf
        fromTemplate: "配置文件模板 ID 或唯一名称"
        values:
          port: 8080
```

“应用部署 → 应用配置文件”保存 nginx.conf、application.yml、.toml 等文件的内容模板，并非平台设置或整套应用模板。配置模板使用 `{{ .Values.port }}` 参数。标记为密钥的参数填写已有变量名；预览仅显示引用，实际内容随部署快照加密保留。目标配置文件为只读挂载；Swarm 通过版本化 secret 分发到任务节点，不能使用 manager 本地路径冒充远程节点挂载。native 的环境文件会保留，以便主机重启后仍能启动服务。

## CSV／XLSX 导入导出

普通可创建资源支持“下载模板 → 上传 → 预览 → 确认新增”。每次最多 1000 行、8MB，XLSX 解压内容最多 32MB。模板第一张工作表为数据表，第二张为字段说明。复杂定义、字典项、参数及权限／标签数组使用对应字段的 JSON 或文本格式；引用填写当前空间 ID。

导入只新增，不自动覆盖现有记录。预览执行相同的权限与业务校验，但不保留资源和审计变更；错误注明原始行号。全部通过后才能确认，提交时再次检查权限和引用；任一行失败则整批回滚。重复或并发确认不会重复创建。

密钥列在预览中遮蔽，待确认数据加密并绑定当前用户、工作空间及资源。取消会删除待确认数据；成功提交后清空待确认密文。默认不设置自动清理期限。上传的 XLSX 不能包含公式。

导出包含当前筛选及排序下的全部记录，不限于当前页面；沿用列表读取权限和公开字段，不导出凭据密钥或秘密变量值。CSV 对公式开头的文字加保护前缀，XLSX 使用文本单元格。XLSX 单元格最长 32767 字符，较长的定义请使用 CSV。历史记录、成员列表等只读资源支持导出，不支持导入执行记录或代替成员邀请。

主机的 `tag_ids` 使用 ID 字符串数组。编辑省略该字段会保留关联，显式 `[]` 会清空；引用中的标签不能删除，先从主机移除后再删除。

## alpha.7 实际环境验收

以下用于安装后的人工试用，不代表已经在你的机器或第三方账号上验收。建议先使用独立测试空间和测试主机；K8s／Helm 不在本轮范围内。

| 顺序 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 首次安装，服务地址留空，打开工作空间 | 内置服务启动，连接设置窗口隐藏，可以进入初始化或登录页面；没有默认超管密码，首次需人工设置。 |
| 2 | 完成一次连接后，从托盘退出，再重新打开应用 | 直接恢复已选择的工作空间，不要求重复填写连接设置；托盘可能位于系统折叠区域。远程地址也单独验证一次。 |
| 3 | 分别验证“仅为我”和“所有用户”安装；从 alpha.6 发起更新 | 沿用原安装范围，不重复要求选择范围或先卸载；等待进行中的工作完成后安装并自动启动，恢复工作空间。系统要求的管理员提权仍可能出现。alpha.4 首次过渡升级应先结束任务再运行新安装包。 |
| 4 | 初始化超管，创建测试空间，再用普通成员登录 | 超管可进入平台管理；普通成员仅按空间角色访问资源，不能获得平台管理权限。 |
| 5 | 连接实际私有仓库，再同步一个市场索引 | GitHub／GitLab／Gitee 在管理员配置 OAuth 应用后可网页授权；Codeup 使用 API 凭据。私有内容能读取，重新授权后原仓库引用仍可使用。配置方式见[外部仓库授权](repository-connections.md)。 |
| 6 | 部署测试应用，修改普通变量、秘密变量和配置模板，更新后回滚 | 工作负载运行；回滚恢复旧版本产物和当时的变量／配置，而非重新读取当前模板。页面和导出不泄露秘密值。旧凭据是否仍有效取决于外部服务。 |
| 7 | 主机组部署中让后续测试目标失败 | 已成功目标保留新版本，失败目标记录原因，后续目标跳过；详情能区分每台主机状态。 |
| 8 | 下载导入模板，先上传一份含错误行的数据，再修正并确认 | 错误预览不创建资源；修正后一次创建，重复确认不重复创建；导出遵循筛选，且不带密钥明文。 |
| 9 | 配置测试定时任务和告警，制造异常再恢复 | 时区和运行记录符合配置；持续异常保持一个未恢复事件，恢复后记录恢复；配置的测试 Webhook 在触发和恢复时各发送一次。 |

反馈问题时请记录：应用版本、操作系统、安装范围、使用内置服务还是远程地址、操作步骤、预期与实际结果，以及发生时间。部署／流水线问题附执行 ID 和相关错误输出；不要附令牌、密码或秘密变量明文。截图可用于说明窗口、托盘或页面表现。


## 流水线引用构建变量

在“构建 → 密钥变量”管理普通／秘密变量，流水线定义通过环境项引用：

```json
{
  "workdir": "/tmp/build/{{run}}",
  "env": [{"name": "PACKAGE_TOKEN", "valueFrom": "variable/package-token"}],
  "steps": [{"name": "build", "run": "./build.sh"}]
}
```

每个环境项的 `value` 和 `valueFrom` 二选一。变量按全局、构建模块、当前流水线依次覆盖；找不到引用时拒绝触发。触发成功即固定加密快照，后续排队期间轮换变量不会改变该次执行。变量值不再解释 `{{run}}` 等占位符，保留原始内容。流水线模板的秘密参数也只能生成 `env[].valueFrom` 引用，不能将明文插入命令。

执行详情显示变量来源和版本，不返回值。远端环境写入私有脚本，不拼入启动命令参数；标准输出和错误输出在入库前脱敏。加密快照随执行历史一并清理，默认保留规则不变。正在被流水线选择的变量不能直接删除，需先调整引用。


## 应用部署表单

创建和编辑应用默认使用表单。逐个添加服务，填写镜像或 Native 构建产物、端口、环境变量、数据卷和应用配置文件；命令参数、服务依赖、HTTP 健康检查、CPU／内存限制位于服务的高级配置中。依赖通过选择服务表达，不使用拖拽或流程图。重命名服务会更新对应依赖，仍被其他服务依赖时不能删除。

环境变量可选普通文本或 `variable/变量名` 引用；密钥应使用引用。应用高级配置可设置更新策略，Swarm 可选 rolling。模板生成的配置直接进入同一表单，不另建编辑流程。配置文件参数、标签与模式覆盖保留 JSON 对象编辑。

“源码编辑”可处理完整 YAML／JSON，包括表单未展开的高级字段。切换编辑方式不会重置内容，表单修改只更新对应字段；语法错误会阻止保存，JSON 参数未修正前也不能切换源码。YAML 别名或无法安全显示的结构保留原文并提示使用源码。保存仍由服务端校验当前部署模式的支持范围，并沿用原有 JSON 规范化存储（不保留注释）。
